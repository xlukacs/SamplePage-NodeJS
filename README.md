# SamplePage-NodeJS

A version of [SamplePage](https://github.com/xlukacs/SamplePage) served by Express on Node.js. Try the counter, greeting, and dark-mode toggle.

## MadRent

Select **GitHub repository** and **Dedicated VM**, then choose this repository's `main` branch.

Choose **Node.js Web Service** and **pnpm**. Leave **Build command** blank and use the default port 3000.

Open `/api/health` for JSON or `/` for the sample page.

## Run locally

```sh
pnpm install --frozen-lockfile
pnpm start
```
